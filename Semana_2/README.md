# 🤖 Aprendizaje Automático — Semana 2

### Adquisición, inspección y visualización de datos

Actividad correspondiente a la **Semana 2** de la materia **Aprendizaje Automático**, orientada al trabajo con diferentes fuentes de datos utilizando **Python**, **Pandas** y **Matplotlib**.

## 📌 Objetivos

- Importar y manipular datos desde archivos **CSV, JSON y Excel**.
- Combinar diferentes fuentes de datos mediante identificadores comunes.
- Realizar una inspección inicial de conjuntos de datos con **Pandas**.
- Aplicar técnicas básicas de visualización con **Matplotlib**.
- Analizar relaciones, distribuciones y posibles valores atípicos.

## 📊 Actividades realizadas

**Ejercicio 1 — Adquisición de datos**

Se trabajó con información ficticia de una empresa de comercio electrónico, utilizando datos de ventas, clientes e inventario almacenados en diferentes formatos.

**Ejercicio 2 — Visualización de datos**

Se analizó el dataset `Automobile.csv` mediante gráficos de dispersión, histogramas, diagramas de caja y gráficos de barras para explorar características de los automóviles.
